## 选择安装包

打开[下载页](/zh-cn/download/)或 [GitHub Releases](https://github.com/yangheng95/opencorvus/releases)，
从同一个版本中选择与你的操作系统和架构匹配的产物。
OpenCorvus 仍在积极开发，安装或更新前请阅读该版本的发布说明。

- **桌面使用：** 选择对应平台的 Windows 安装器、macOS 磁盘映像或 Linux 软件包。
- **命令行使用：** 解压完整的 `opencorvus-<platform>.tar.gz` 运行包，
  保持主程序及配套文件在一起，并把可执行文件所在目录加入命令搜索路径。

根据该版本的 `SHA256SUMS` 校验下载文件。桌面安装器与命令行运行归档是不同的包，
请按用途选择。当前可用格式以下载页和版本发布说明为准。

## 验证本地运行环境

命令行使用时运行：

```bash
opencorvus --version
opencorvus doctor
```

`doctor` 检查本地平台能力，例如原生模块和 shell。
它不会发送模型请求，也不验证模型服务凭据。使用某项能力前，
先检查与该能力相关的警告。

仓库和工作树操作需要 Git。部分 Skill 还需要 Python；
请按实际使用能力的说明准备依赖。

## 从源码构建

源码构建需要 Bun 1.3.14 或更新版本，以及 Node.js 22 或更新版本。
Windows 上还需先准备 Rust/Cargo 和 Visual Studio C++ 构建工具；
请按仓库的 [Windows 工具链说明](https://github.com/yangheng95/opencorvus/blob/788980e7eecc1a86be91d6876fa296a28eb14f93/CONTRIBUTING.md#windows-runtime-tests-and-binary-builds)完成设置后再构建。

```bash
git clone https://github.com/yangheng95/opencorvus.git
cd opencorvus
bun install
bun run package:native-binary
bun packages/opencorvus/src/index.ts doctor
```

完整运行包与归档位于 `packages/opencorvus/dist/`。
原生打包还有平台相关的依赖要求，参见仓库的
[打包指南](https://github.com/yangheng95/opencorvus/blob/main/LOCAL_PACKAGING.md)。

## 配置模型并开始

继续阅读[快速开始](../quickstart/)，配置精确模型、启动运行环境，并检查第一份成果。
模型与凭据必须属于同一个提供商；配置方式见[模型提供商说明](../../providers/)。
